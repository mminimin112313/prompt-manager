# ADR 001: UI 상태 관리 중앙화

## 상태
승인됨 (Accepted)

## 맥락 (Context)
기존 프로젝트에서 사이드바의 "새 항목 추가" 버튼이 메인 뷰의 프롬프트 에디터와 연결되지 않아 작동하지 않는 문제가 있었습니다. 이는 컴포넌트 간의 가시성 상태가 개별적으로 관리되어 동기화가 이루어지지 않았기 때문입니다.

## 결정 (Decision)
UI의 가시성 상태(에디터 오픈 여부, 편집 중인 ID 등)를 `uiStore.ts`로 통합하여 전역적으로 관리하기로 결정했습니다.

### 변경 이유:
1. **사이드바-메인 뷰 동기화**: 사이드바의 버튼 클릭 이벤트가 메인 뷰의 컴포넌트 렌더링에 즉각 반영됩니다.
2. **코드 단순화**: 복잡한 이벤트 디스패칭(Event Dispatching) 대신 스토어 구독 방식을 사용하여 로직을 명확하게 유지합니다.
3. **확장성**: 추후 다른 모달이나 사이드바 제어 시에도 동일한 패턴을 적용할 수 있습니다.

## 결과 (Consequences)
- `isEditing`, `editingPromptId`가 `uiStore`에 추가됨.
- `+page.svelte`의 로컬 상태가 스토어로 대체됨.
- 사이드바 버튼이 정상적으로 작동함.
